# Etapa 3

- A estrutura de navegação do projeto se manteve a mesma, com stacks das páginas. Assim, o menu principal tem a stack de todas as páginas que consegue acessar dali, e outras telas têm stacks de telas secundárias que só podem ser acessadas a partir delas.

- O mecanismo de acesso às páginas que foi alterado para se adequar aos princípios que vimos de UX. O principal objetivo foi facilitar o alcance da navegação com o polegar. Decidi fazer um menu circular, logo ao lado do ponto de rotação do dedão. Assim que pressionamos ele, vemos as outras possíveis telas que podemos navegar, ou cancelar a ação.

- Esse menu também foi implementado com animações para o toque parecer mais responsivo e flúido
