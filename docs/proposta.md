# ETAPA 1 — PROPOSTA E PLANEJAMENTO DA APLICAÇÃO MOBILE

## Especificações do APP

- ### Nome da aplicação; 
    My Hub 
- ### Problema que a aplicação pretende resolver;         
    Problemas do dia a dia, como agenda, listas de compras, organização financeira, etc...
- ### Público-alvo; 
    jovens adultos ou mais velhos
- ### Objetivo principal; 
    centralizar em um só app tudo (ou quase) que se precisa para organizar os a fazeres do dia a dia, com o máximo de integração dos dados entre si
- ### Descrição das principais funcionalidades; 
    as funcionalidades desse app são modulares, então são praticamente infinitas. Porém, para começar as principais são: 
1. agenda, podendo adicionar tarefas, compromissos, alarmes...
2. planejamento financeiro, funciona como uma planilha de controle de dados, para separar em categorias os gastos em um período de tempo. Provavelmente também uma funcionalidade de planejamentos para o futuro. 
3. lista de compras, a princípio bem simples, como uma checklist. Talvez poder adicionar membros da familía.
- ### Pelo menos 4 telas previstas para a aplicação; 
    Menu principal, tela de configurações, agenda, lista de compras, planejamento financeiro
- ### Fluxo básico de navegação entre essas telas; 
    menu principal teria a navegação para as outras telas. o planejamento financeiro ficará dentro da categoria financeiro, onde também teremos a tela de gastos. cada tela com um botão de voltar à tela anterior. 
- ### Tecnologia escolhida para o desenvolvimento mobile; 
    React Native
- ### Tecnologia escolhida para o backend, caso exista;
     Node.js
- ### Necessidade ou não de comunicação com APIs externas; 
    Provavelmente. Penso que pode ser útil pegar taxas de investimentos para a parte do financeiro.
- ### Forma prevista de armazenamento de dados; 
    banco de dados SQL
